BEER - configuration files for neutron ray-tracing simulation
SIMRES, ver. 6.3.6
=========================================================

Configuration
===============

BEER_new_primary.xml:
Detailed model of the primary diffractometer (source-sample). 


Tables
=========
ESS2016_W2_cold.tab, ESS2016_W2_thermal.tab:
Source tables for the cold and thermal parts of the ESS butterfly moderator. It assumes 10 ms total pulse length (primary pulse + afterglow), to be used with source delay = 3.4 ms. 

ESS2016_W2_cold_5ms.tab, ESS2016_W2_thermal_5ms.tab:
As above, but with shortened afterglow tail (total length 5 ms, to be used with source delay = 0.9 ms).

Scripts
=========
BEER_new_modes.inp:
Commands for setting and simulation of the reference + other settings. See the comments at the command groups for description.

BEER_new_setup.inp:
Commands for setting up parameters of the BEER components. Employs commands generated by the script BEER_simres.py.
