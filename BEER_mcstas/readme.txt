BEER - configuration files for neutron ray-tracing simulation
McStas, ver. 2.5
=========================================================

Configuration
===============

BEER_primary.instr:
Detailed model of the primary diffractometer (source-sample). 

BEER_reference.instr:
The same as BEER_primary.instr, but with less input parameters for easier simulation of the predefined reference modes. 

See description in the file header for more detaiils.
The files are generated by the script "BEER_mcstas.py" using the template "BEER_primary.instr.template" and the BEER geometry and components definitions in BEERgeometry.py and BEERcomponents.py. 

Compile
=======
compile.bat:
Windows batch file for compilation of  BEER_primary.instr (edit paths etc to match your environment). 

runit.bat:
Windows batch file for running BEER_primary.exe with output to a directory given as an argument.
