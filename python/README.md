# beer_optics

Neutron optics model for the diffractometer BEER at the European Spallation Source.  
Author: Jan Saroun, saroun@ujf.cas.cz  
Copyright (c) 2020 Nuclear Physics Institute, CAS, Rez

## Contents

### python

- `BEERgeometry.py`: Definition of the beam axis and profile. This is the single source of beam geometry data for all outputs, such as component table, SIMRES and McStas configuration files etc. It also provides functions for coordinate conversions, beam dimensions at arbitrary positions etc.  
- `BEERcomponents.py`: Definition of BEER components. This is the single source of information about all components included in the BEER Component List (ESS-0478295). The script generates the contents of the BEER Component List (ESS-0478295) in plain text format, see *data/components_list.txt*.
- `BEER_beamaxis.py:` Calculates a long table *BEER_beam.txt* with beam axis coordinates in three reference frames (TCS, W2, ISCS), intended for verification of the instrument design. It is also used by other scripts to generate simulation configuration files (McStas) or scripts (SIMRES).
- `BEER_mcstas.py`: A script for generation of McStas instrument file (BEER_primary.instr).
- `BEER_primary.instr.template`: A template used to generate *BEER_primary.instr* for McStas, the simulation model for the primary beam (source to sample).
- `BEER_simres.py`: Generates input script for SIMRES, *BEER_setup.inp* with commands which set component parameters according to the actual beam geometry and components as defined in *BEERgeometry.py* and *BEERcomponents.py*. The script must be applied to a compatible SIMRES configuration file with the same sequence of components. An example is provided in `data/BEER_new_primary.xml`. 

### data
Outputs of the beam data for the current geometry version:
- `components_list.txt`, the contents of the components table, ESS-0478295.
- `BEER_beam.txt`, a table with beam axis coordinates in three reference frames (TCS, W2, ISCS).
- `BEER_primary.instr`, McStas instrument file as generated by *BEER_mcstas.py*.
